# zain-ayesha-shaadi
Vintage botanical South Asian digital Shaadi invitation. A single-file site built with Tailwind (CDN) and vanilla JS, with a royal blue and gold cover, three themed event pages (Mayoon, Baraat, Reception) and a live countdown. All botanical art is inline SVG.

A mobile-first digital wedding invitation inspired by vintage Indian miniature paintings and luxury editorial stationery. The whole project is one index.html, with no build step and no image files.

Pages

Cover: royal blue and gold, with a scalloped botanical border, the Bismillah with its English translation, and a Z + A monogram
Mayoon: marigold yellow with dusty rose and sage botanical framing, plus drifting petals
Baraat: oxblood maroon, sand and antique gold, with lily corners, an arch motif and a live countdown
Reception: misty lavender and silver with a hairline frame

Stack: HTML, Tailwind CSS via CDN, vanilla JavaScript, inline SVG, CSS scroll-snap

Customise: edit the countdown date (TARGET) at the top of the script, and swap the names, venues and times directly in the HTML.

Deploy: push to GitHub and enable Pages, or open index.html directly.

The page loads Tailwind and the Google Fonts from the internet, so it needs a connection on first load. The artwork itself is all inline, with no image files to break. If you'd rather say "works offline" in the README, I can bundle the CSS and fonts first.
